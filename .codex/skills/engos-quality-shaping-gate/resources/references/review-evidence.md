# Review evidence v1 / G3 receipt v2

Apply this protocol only to future policies with `review_evidence: true` and a
new policy ID. Missing/false preserves schema-1 history; never migrate implicitly.
Schema-1 receipts and accepted snapshots remain immutable. G3 receipt v2 retains
all ordinary binding/scoring/assessment fields and adds `review_evidence`.
`next_state` remains the assessed gate. Returns recommend repair, never transition.

Seal the author subject first. The controller constructs a deterministic ordered
packet from the sealed outputs (including registers and source/render artifacts),
pinned inputs and policy resources. Every entry binds portable path, SHA256 and
whole-file text span where UTF-8. The packet binds run, order, policy, return hash
and assigned reviewer. It does not include future observations. Host opening and
semantic/visual observations occur AFTER seal and bind this immutable packet hash.
The controller separately records the host sidecar with `review-observation`;
the receipt references its path/hash. Receipt-held opening assertions alone hold.
There is no circular pre-seal reviewer evidence requirement.

Host observations are trusted controller records, not authenticated identities or
proof of reading generated by this helper. Require actual ordered openings and
stable identities from a capable host; unavailable attribution/opening capability
holds review. Test observations must be labelled fake. The host must protect its
records and controller store. Hashes establish bytes, not truth or independence.

A source quote carries packet path/hash, inclusive line locator and exact actual
quoted bytes. Review each existing seam's receiving function, actual field read
span, field path/type, proposed expression, input, message and accepted proof.
A new predicate over an existing read is legal even when proposed behavior is
absent. Comments, unrelated fields and relabelled existing seams are not grounding.
Explicit new/nontechnical applicability requires source-backed reason and review.
Semantic judgments are independent assertions; never infer truth by regex or
sentence equality. Require a structured contradiction audit of rationales.

Every in-scope unanswered question requires its own exact question/proof-bound
nondependence quote and independent judgment. Dependent questions require the
named respondent's observed authority/provenance and answer; a fixer cannot answer
on that person's behalf. Preserve independent defects even when renders are absent.

Each diagram binds source and render SHA256, a readable image and host observation.
PNG decoding rejects malformed/blank images; safe SVG additionally requires a bound
PNG rasterization from the host renderer. Inspect actual pixels for labels,
connectors, visible content and source agreement; helper checks do not replace this.
Missing/unusable renders require an independent `diagrams_visual` hold finding.

Each typed finding has unique ID, failed assessment check, quote, repair, route,
status and optional prerequisite ID. Routes: `review_hold` for renders or missing
host capability; `research` for unsupported predicates; `shaping` for established
predicate/input-message mismatch; `respondent` for dependent questions. Every failed
check has relevant findings; passing checks cannot carry unresolved findings.
Pass requires no findings/blockers, all assessments and structured checks passing,
and all twelve finite numeric scores >=3 with recomputed mean >=4. Booleans fail.

Record host-observed participation in a hashed prepare input: stable author and
reviewer IDs, all contributors and repair records. A fixer must differ from author
and reviewer, have explicit user consent before contributing, and joins authorship
of the revision. Any contributor, including a renamed fixer, cannot next grade.
Unavailable identity holds. Supplied strings never authenticate identities.

The controller pins `accepted_proof` at G3 prepare to an accepted G2-owned quoted
source and exact proof text. Review plans cannot substitute it. Final host sidecars
attest all sealed revision contributors; changed membership requires fresh prepare.
Every contributing fixer binds a recorded failed work order, return hash and finding,
and matching original author/reviewer, plus prior user acceptance. Contradiction
audits bind the actual score/assessment rationale bytes and relevant source/subject;
false consistency with no structured contradictions holds. Routes must be owned by
structured failures and prerequisites must be acyclic.

For a score/assessment rationale contradiction outside a declared seam/question,
use item `assessment:<check>` and a failed assessment owned by that check. Bind
its exact rationale bytes and actual source quote from that assessment's or score's
cited evidence inventory, with a `shaping` return. This permits scope, appetite,
cost and other twelve-score contradictions without claiming machine prose truth.
Special seam/question contradictions retain their structured research/shaping/
respondent routes and cannot be reclassified through a generic audit item.

When an independent generic score contradiction shares a broad check with a
special seam/question failure, require its actual score rationale (not that
shared assessment explanation) and a source span disjoint from every special
failure source under the check. Compare paths and hashes so identical copied
sources cannot evade span overlap. Preserve both owned findings and their routes.
Disjoint evidence proves separate byte spans only; independent review must still
judge whether the defects are substantively independent. V2 score/assessment
citations may reference pinned packet inputs as well as sealed subject artifacts.
