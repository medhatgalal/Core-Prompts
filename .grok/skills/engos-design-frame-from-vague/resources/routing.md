# Framing resource routing

Read only `intake` or `frame` and its complete dependency closure. The route is a
resource selector, not a CLI. Resolve cross-skill resources from the host registry
or explicit candidate binding, recording SKILL path, resource root and revision.
`registry(<slug>).resource_root` means the resolved root, not a literal API/path.

Read `engos-design-shaping` SKILL and its `routing.md` when this is a direct framing
request, then load its `start` route. Under an existing conductor work order reuse
the current bound originals and state; do not restart the interview.

For Intake, read the conductor's `dispatch.md` and `sources.md`. For Framed, read
its `dispatch.md`, `questions.md` and `decisions.md`; load `human-evidence.md` only
when a teammate/evidence request is needed. Read all required dependencies of those
routes. No shaping, publication, code-scan or numeric rubric resource is loaded
merely to normalize an intake.

For actual G0/G1 review read `engos-quality-shaping-gate` SKILL and selected gate
resources. Gate predicates belong there. A missing required package routes to the
conductor's `fallback.md`; candidate writing cannot manufacture accepted state.
