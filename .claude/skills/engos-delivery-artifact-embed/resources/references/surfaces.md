# Surface placement contract

Native Mermaid is preferred where actually supported. Verify the target renderer
and its current result rather than assuming all wiki/chat/PR surfaces support it.
HTML/PR/MR use source fences and complete Markdown tables. Chat may require an
authorized image reference. Wiki uses an enabled Mermaid macro or attached PNG
plus native tables. Google Docs requires source-bound PNGs and native tables.

For full shaping, placement follows current G3 approval and uses its immutable
source inventory. Artifact-only placement remains allowed without claiming the
earlier shaping stages passed. Read export.md before local conversion.

## Private Google Docs path

Identify the work account and destination before writing. Prepare complete DOCX
with the same source prose, rows and three PNGs, render and inspect all pages.
Use the host's supported native document import route. Where the user requests
GWS, inspect current schema/help and use supported `--upload`, not a reported
blocked `--upload-file` form. No public sharing or public image URL prerequisite.

The reported insertInlineImage/public Drive sharing failure is known. Prefer
embedded image bytes through DOCX conversion; don't repeatedly rediscover the
public-URL restriction. An actual policy denial stops that operation. Do not
switch tools to evade it. Syntax compatibility is different from policy denial.
Use documented browser actions with fresh state, not hardcoded historical
app_post/sky_click names from another host.

Record publication intent bound to approved source, surface and destination
before writing. After uncertain success, locate/read back the same target before
retrying. If it cannot be uniquely identified, return reconciliation_required
instead of creating a duplicate. Current saved native Doc must contain every
inline diagram and every native table row; inspect its exported/rendered pixels.
Successful local DOCX creation or upload acknowledgement alone is not placement.

House style: Title 18pt, H1 13pt, H2 11.5pt, bold/color hierarchy; body 11pt is the
documented default. No underlined title rules. Preserve full tables and captions.
Use approved target colors where available. Wider tables may require landscape
or deliberate widths; do not drop rows to fit a screenshot.

Return source and target identities/revisions, full inventories, readback evidence,
pixel observations and exact status. A human insertion step remains placement_pending.
Keep content review passed while reporting delivery blocked. Do not auto-share,
notify teammates, change scopes or treat publishing as a human bet.
