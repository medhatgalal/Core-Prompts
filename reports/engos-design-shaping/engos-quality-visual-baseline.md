## Observed design language

- Subject-first title in strong blue, italic muted stage/subtitle, green metadata
  heading; stage and appetite appear before the main story.
- Primary numbered headings in blue, subordinate headings in green; generous
  section spacing and readable body text. Framing stays prose/list based, solution-free.
- Shaped narrative introduces each figure; figure titles, captions, legends,
  deliberate boundaries and status colors explain the drawing. Figures appear
  with their corresponding architecture/sequence/contracts sections.
- Native tables use compact four-column views, dark-blue headers with white text,
  and explicit state labels with green/amber/blue/neutral fills. Color is redundant
  with text; it is not the sole indication of meaning.
- Detailed figures are composed to page width, not giant horizontal graph strips.
  Table continuation remains legible. One reference table continues without its
  header and one caption sits across a page boundary; these are not defects to copy.

## Acceptance sheet

Mandatory: readable sustained text at normal view, intact visible captions/legends,
no inaccessible clipped content, no broken-word columns, full field/row parity,
native editable Docs tables, meaningful color/text distinctions, truthful status,
no selected solution added to Framed. Titles/heading sizes follow the user's
Title18/H113/H211.5 convention; reference color hierarchy takes precedence over
generic black-heading presets. No requirement to reproduce source claims or names.

Check HTML at 375/1280/1920 CSS pixels and Letter document output at normal view.
For wide information use a concise primary view plus stable-ID supporting detail,
not smaller fonts to force thirteen columns. Every original field must remain
reachable and exactly represented. Use real lists/emphasis/links and narrative
sections, not literal Markdown syntax or one paragraph per wrapped source line.

SVG and high-resolution PNG must bind to editable source and a recorded renderer;
place figures at explicit section anchors. Assets need captions, alt text,
dimensions and full-size access. Native Mermaid remains a compatible source path;
rich self-contained exports use verified local assets and must pass offline load.
Untrusted SVG/scripts/external references must not execute. A curated SVG layout
may be used with a stated layout reason and semantic comparison to its source;
no fabricated diagram internals. Do not turn complete tables into screenshots.

Fixtures: the existing role pilot's thirteen-column contract table and three
diagrams; existing model-capacity teaching bundle; short solution-free frame;
long-cell/page-break, long-label, missing/stale/malicious asset and unsupported
format cases. Automated output checks and independent full visual inspection
are separate gates. Existing rendering/placement receipts are not new-output proof.

Owner of checks: controller gathers scoped reference/candidate images; independent
visual reviewer judges candidate readability/fidelity; code reviewer verifies safe
asset/field mapping. When style conflicts with readability, preserve meaning and
record the intentional deviation. No public publication of private sample content.
