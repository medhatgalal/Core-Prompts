## Implementation notes and limits

Classification uses the exact digest of canonical `encoded(policy_bindings)`. Before policy comparison it verifies the stored policy hash against that order's own bindings, event/order identity and version, reviewer actor, sealed subject hash, provenance digest syntax and path bindings, captured receipt schema/identity/subject bindings, and immutable G2 predecessor. Work-order IDs are checked before dictionary lookup. History is classified from the review captured in the content-addressed journal; classification does not require the original receipt file to remain present or unchanged. Only a verified different-policy event bypasses current scoring and coverage interpretation. Current-policy classification retains the existing twelve-dimension minimum 3 and overall 4 floor logic.

Legacy journal events retain parsed JSON, not original receipt bytes. JSON whitespace cannot be recovered to recompute the original provenance digest. These checks therefore do not authenticate a syntactically valid forged provenance digest; the captured history and common bindings are protected by journal content addressing within the existing controller trust boundary. No new historical metadata or schema fields were required. All receipts remain FAKE mechanical fixtures, without independent semantic proof.

The local installed-backup copy at `reports/shaping-evidence-recovery/installed-backup/shaping_run.py` was reviewed for diagnostic evidence. Its different-policy fast path precedes shared envelope validation, so it was not adopted wholesale. The canonical source remains the only runtime implementation changed.
