# Proposed shared-doc insertions

Controller integrates these into current shared docs after canonical UAC. This is source preparation, not delivered documentation.

## README.md

Choose the job by its outcome: `engos-meta-supercharge` hardens an artifact (including its candidate versions), `engos-reconciliation-converge` reconciles conflicting sources with attribution, and `engos-optimization-auto-research` measures outcomes against a baseline. These jobs do not form an automatic chain.

For shaping, use `engos-design-shaping` to conduct the workshop, `engos-audit-pitch-review` to assess a finished pitch directly, and `engos-quality-shaping-gate` for actual transition policy. Ordinary plans belong to `engos-design-plan-implementation`; a separately requested bounded packet belongs to the current `engos-design-plan-to-goal` compiler. Compiling a packet does not start a goal or activate `engos-orchestration-batman`.

## docs/GETTING-STARTED.md

Start from the deliverable you need. Harden a plan with `engos-meta-supercharge`; reconcile dated conflicting proposals with `engos-reconciliation-converge`; request a baseline comparison with `engos-optimization-auto-research` only when measured outcomes are needed. Explicit SuperCharge module choices remain valid.

A finished pitch can go straight to `engos-audit-pitch-review`: missing Intake, Framed and Research evidence is reported as unassessed. Actual workshop transitions require the current gate owner and receipts; a favorable review does not record human acceptance. Use `engos-design-plan-implementation` for an ordinary plan or `engos-design-plan-to-goal` for a separately requested bounded packet. Neither starts runtime work or Batman automatically.
