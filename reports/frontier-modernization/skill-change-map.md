## Deliberate Non-Claims and Remaining Evidence

- Candidate authorship and source review do not prove cross-model efficacy.
- Real tool delivery does not prove comprehension; resource-dependent runtime checks are still required.
- Model table sources provide provider recommendations, not local measured remedies.
- Gaslight, contract usefulness, and grade stopping require bounded comparative experiments before claiming effectiveness.
- Independent reviewers should inspect candidate/resource identity, route behavior, authorization, actual candidate iterations, and failure handling without author verdict anchoring.
- Root must run UAC same-slug review/apply and generated-surface validation serially. No SSOT, descriptor, or generated surface was hand-edited by this worker.
