# Freshness repair review checkpoint

Status: draft / hold for complete live acceptance and explicit graph-scope decision.
This is an implementation checkpoint, not promotion or authority to merge.

## What changed

The standalone skill and the three existing caller gates remain. Evidence v2 makes
the Python result mechanical collection validation only; the same source-reading
agent must make the final technical assessment. No fourth automatic caller,
provider installation, runtime hook, message, deployment or release is introduced.

The source-neutral contract replaces the provider allowlist and exact endpoint
set. Sourced inventories retain applicable extra, nested and mixed discussion
channels. Repository/owner query receipts, inspected interface evidence and scoped
owner excerpts are bound separately. First design needs a real requirement
revision, not invented design history. Partial coverage retains a frontier.

Native-shaped regressions cover structured events, REST reviews without edit
metadata, actual acquisition after collection begins, mixed timelines and duplicate
canonical content observed at different locations. Notes/events and attempted/read
counts stay distinct. Synthetic source-only input has a separately held expected
outcome; transport fixtures are explicitly not discovery tests.

## Reproduced defects and disposition

- Rejected complete input solely because its tracker was not named: repaired.
- Omitted a linked codehost issue's repository merge search: repaired.
- Rendered a lifted-blocker quote as a final blocked verdict: repaired by separating
  mechanical evidence checks from same-run semantic adjudication, not by regex.
- Accepted wrong-scope owner excerpt or unopened API listing: repaired.
- Lost per-owner query terminals or partial unknown-baseline evidence: repaired.
- Rejected real documentation-only merges, structured events or post-start review
  acquisition: repaired; missing chronology remains an explicit limitation.
- Miscounted events/overlapping observations as distinct notes: repaired.
- Literal recursive expansion can leave the actual work area: NOT resolved by
  dropping records. The scope decision remains open; current rule stays strict.

Two fresh hostile reviewers and a separate repair decider were used. Exact current
and historical entry/resource review bindings are in the adjacent reviews folder;
UAC admission and generated/hosted results are recorded separately.

## Live-source trial: do not overclaim

A fresh source-reading agent ran the original published revision against an
actual privately held work incident. It received the root, frozen skill and tools,
without the independent oracle or retrospective. An independent verifier checked
raw source/terminal receipts, aliases, the result and observed tool access. No OS
isolation, prospective discovery, broad model improvement or complete traversal
was established. The trial is current-state verification with hindsight.

The source-supported technical conclusion rejected an obsolete dependency claim,
identified a potential replacement API, corrected a release/version claim against
actual tagged source, and kept target availability and design implications
conditional. Full graph coverage was incomplete: unresolved records, ownership
histories and uninspected media remained. Source-record presence does not prove
model reading or comprehension. The actual raw data, source URLs, quotations and
work identities remain private outside this repository; none is a public fixture.

The original trial's budget and incomplete outcome are preserved. Do not revise
its scope afterward and relabel it a pass. A revised scope/candidate requires a
separately declared verification phase and truthful fresh/revalidated evidence.

## Remaining limits

The checker validates supplied normalized assertions; it cannot authenticate a
source, establish undisclosed visibility, prove full model consumption or resolve
quote meaning. Missing source capabilities or material currency still hold the
agent's dependent assessment. Direct architecture requires standalone invocation;
only the three requested callers have automatic steps.

## Contract Spec

Fixed acceptance: generic source coverage and scoped owner evidence, current-state
reconciliation before dependent planning, exact requested report, and no unsupported
technical blocked verdict. Mechanical source checks and package transport cannot
supply semantic approval. Every currently declared recursive link remains required;
no scope exception has been inferred from silence. Full live coverage remains a
separate failed/pending gate despite correct targeted technical findings.
