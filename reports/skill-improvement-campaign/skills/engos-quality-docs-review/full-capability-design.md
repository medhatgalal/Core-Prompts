## Alternatives, recommendation and flip conditions

**Recommend revised trial C1-r1: reader-task workflow with integrated review lenses and
adaptive output.** The original draft is preserved in acce6f6; the current complete draft is `candidate/engos-quality-docs-review.md`.
It reorganizes the source around a common evidence/authority workflow, then
reader/navigation, onboarding/authoring, provenance/drift and release lenses.
It includes scoped repair readback, uncertainty handling and explicit adjacent
handoff semantics. These are coupled changes intended to improve whole-job output,
not an attribution claim for each sentence. The body is larger than the incumbent;
its usability and context overhead must earn their cost in downstream trials.

**Retain incumbent** if C1 ties, adds noise, degrades any major job or requires more
operator work than the preregistered limits. Existing evidence and boundaries are
substantive; absence of demonstrated failure makes preservation defensible.

**Focused H1 amendment** remains a fallback if C1 improves drift but not authoring,
reader success or repair reliability, or if whole-body overhead is excessive. It
must be a subsequent frozen candidate/comparison, not credited with C1 results.

**Modular resource redesign** could move authoring/tool guidance behind a complete
route if real traces show unnecessary context consumption. Not chosen now: the
current job is small enough for a single readable source, and a module adds delivery
failure modes. No fabricated module is required to satisfy a “full capability” remit.

**Separate authoring capability** is not recommended without evidence of a distinct
unmet job. Current Docs already permits requested documentation edits and rewrite
guidance. Instruction Editor owns preservation of executable instruction semantics;
Testing owns test design; Architecture owns product design; GitOps owns hosted
release/merge evidence; Feature Status owns scope-versus-implementation completeness.
Splitting now duplicates these boundaries. Any future addition/routing change goes
to coordinator UAC overlap review, not this owner's canonical edits.

Output simplification: use one verified same-task report or a new noncolliding
task/timestamp report, and replace seven fixed headings with useful content and
caller-selected artifacts. Preserve unrelated existing reports. This is an explicit output-contract change, not a
claim of purely editorial preservation. Exact behavior changes need independent
requirement review before canonical apply; no formal promotion verdict is required
merely to draft or evaluate a development candidate.
