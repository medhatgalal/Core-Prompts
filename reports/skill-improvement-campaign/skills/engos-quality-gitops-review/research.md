## Catalog overlap and boundary decision

Current source inspection gives Code Review the actual diff's correctness/scope/message judgment; GitOps owns current branch/provider/lifecycle readiness. Testing designs tests and distinguishes generated from executed artifacts. Docs owns information architecture and release documentation drift. Architecture owns interfaces, migration and failure/rollback design. Address Review implements selected existing review comments; Conflict Resolution analyzes real conflicts; Batman is an explicitly invoked delivery controller. Engineering Progress reports Git activity, while Feature Status assesses scope completion. Preserve those distinct returns instead of making every GitOps invocation a comprehensive implementation audit.

The original skill repeats companion routing in mission, workflow, rules and a dedicated section. Candidate consolidation into a single concrete handoff table is a simplification hypothesis. It retains specialist requirements and adds receipt status, not an automatic council. Public outcomes must check both missed handoffs and unnecessary duplicate work.
