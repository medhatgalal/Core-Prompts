# Core-Prompts intent routing

Use this rule for Core-Prompts work or a request to use its skills. It is contained
in this package; it does not install a global hook or depend on another repository.
Respect the current project's workflow, host permissions and the user's scope.

When the next useful job, needed depth or workflow continuation is materially
unclear, select the available `engos-route-intent` skill. Read its complete entry
and only the references needed for that decision. Start with the host's supplied
skill inventory and established package context. Do not require a source checkout,
new configuration or a manually supplied catalog path for routine selection.

A clear direct request or already selected skill bypasses intake. Read that owner's
contract and continue already authorized work. Ask only consequential missing
questions; recommendations are not a new approval ceremony. For any selected Core
skill's questions, preserve Other/free text, using the actual compatible question
tool or an inline fallback. A native Other field counts. Preserve actual approval
mechanisms; a displayed default, silence or timeout is not consent.

The routing skill owns the adaptive method and conditional relationship guidance.
The receiving skill owns its actual artifacts, required inputs, reviews and human
decisions. A stale or absent relationship does not exclude an updated skill.
Sequence, return, iteration, support and parallel suggestions do not dispatch work
or prove dependency/write safety. Keep missing evidence and authority explicit.

If a package or needed tool is unavailable, report that fact and use only an honest
bounded manual/inline fallback. Do not invent a tool call, automatically install a
skill, create an agent, change settings or claim native discovery from file presence.

Native implicit skill selection depends on the harness and skill description;
explicit selection remains available. This file does not make every unrelated
prompt a Core-Prompts task. The portable guide and its declared answers are aids,
not an AI service, acceptance evidence or global activation mechanism.
