# Review external edits

"Review edits in this Doc" and resuming its registered link start reconciliation,
not silent synchronization. Obtain last-published source/target baseline, current
accepted source and current saved target. Missing baseline means the comparison
is uncertain: preserve both and ask for the intended base, never last-write-wins.

Capture target edits as a new candidate. Compare by section, table/row and diagram
meaning, showing compatible changes, conflicts and the decision affected. Comments
and suggestions are proposed discussion, not accepted prose or approval. Attribute
direct and relayed answers separately. User edits are preserved while decisions
are pending. Product resolves scope/appetite; engineering substantiates behavior;
an unresolved conflict needs the named accountable owner, not invented consensus.

When a human accepts material changes, reopen affected shaping gates and update
the accepted source only through the controller. Re-export from that revision.
Use target revision preconditions when updating. If unavailable, do not overwrite
concurrent edits; request scoped replacement authority or return a human step.

The run status marks older exports drifted/superseded with current links on
detection. Do not secretly edit an external document to add that warning. No
permission expansion, notifications or broad cloud search is implied.
