# Markdown source and derived representations

Markdown is the human source. Operational JSON state/receipts are authoritative
for acceptance identity, not a second prose copy. HTML and document JSON are
derived views of a specified source revision, with stable IDs and full inventories.
An edited export becomes a candidate for reconciliation, never a silent second
current source. Respect source classification on each destination.

| Representation | Retained content and verification |
| --- | --- |
| Markdown | Full human-readable sections, native tables, Mermaid sources, captions and evidence references; immutable accepted revision |
| HTML | Complete approved prose/tables, all rendered diagrams, captions, source identity and status; inspect saved page pixels for clipping, labels, layout and full row coverage |
| JSON document export | schema_version, source revision/hash, stable section IDs/order/full text, table columns and every row/cell ID, diagram source/caption/evidence and rendered references/status, claim/evidence refs and unresolved status; parse and compare against source inventory |
| Native Google Docs | Full prose, native editable tables with every row, rendered diagrams/captions and source identity; current document/tab/revision readback plus saved-render visual inspection |

A JSON status manifest is not a full document export. Markdown-only and JSON-only
consumers still receive truthful render and publication status; generating a file
is not proof it displayed correctly. Preserve complete tables; a summary view may
supplement them but never replace them under a full-delivery claim.

Use the embed helper's current supported private conversion/insertion path for
Google Docs; read real tool/schema help rather than copying trial-specific flags.
Do not make diagram images public to satisfy a URL requirement. Native Mermaid
support must be verified on the actual target, not assumed from product family.
Keep platform-specific house style in the adapter's resource; inspect requested
style against the saved result. Policy denial stops that operation; a manual
authorized placement may remain pending with an exact check, never bypass access.

Keep source content hashes separate from render/delivery receipts so adding
observations does not change reviewed prose identity. Semantic output changes
require a new candidate and affected gates. Presentation-only repairs need
renewed target checks and a recorded no-content-change comparison.
